# Lumo Minecraft

Minecraft packs and server tooling for the Lumo setup.

## Projects

- [Lumo Optimized](https://github.com/lumo-minecraft/lumo-optimized): performance-focused Fabric modpack with quality-of-life improvements, optimized rendering, and visual polish.
- [Lumo Server](https://github.com/lumo-minecraft/lumo-server): Docker image for a modded Minecraft server with backup and management scripts.
